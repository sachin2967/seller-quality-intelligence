# Claude repository instructions

Read and follow [AGENTS.md](AGENTS.md) before editing or reviewing this repository.
It contains the owner-approved shared workflow, project boundaries and publication
rules used by both Claude and Codex.

- Use your own worktree and a `claude/<task>` branch for implementation.
- Publish tested milestones and create or update the task's draft PR.
- When reviewing a Codex PR, read its latest diff and CI; keep the implementing
  agent as the only writer until ownership is explicitly handed over.
- Keep commits additive, preserve the other agent's work, and leave merging to
  the owner unless a particular merge was explicitly authorized.
